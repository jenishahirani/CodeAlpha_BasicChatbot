
# CodeAlpha Task 4 — Basic Chatbot

## Project Overview
This project is a simple rule-based chatbot developed using Python. It interacts with users through the command line and provides predefined responses based on user input.

## Features
- Responds to common greetings such as hello, hi, and hey.
- Answers simple questions like "How are you?" and "What is your name?"
- Uses a dictionary to store predefined questions and responses.
- Handles unknown messages with a default response.
- Continues the conversation until the user types "bye" or "exit".
- Converts user input to lowercase and removes extra spaces.

## Technologies Used
- Python 3
- Dictionaries
- While Loop
- If-elif-else Conditional Statements
- User Input and Output
- String Methods

## How It Works
1. The chatbot displays a welcome message.
2. The user enters a message.
3. The program checks whether the message exists in the predefined responses dictionary.
4. If a match is found, the chatbot displays the corresponding response.
5. If no match is found, it displays a default message.
6. The conversation ends when the user types "bye" or "exit".

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## Example Conversation

```text
Chatbot: Hello! Welcome to my chatbot.
Chatbot: Type 'bye' or 'exit' to end the conversation.

You: hello
Chatbot: Hi! How can I help you?

You: how are you
Chatbot: I'm fine, thanks! How about you?

You: thank you
Chatbot: You're welcome!

You: bye
Chatbot: Goodbye! Have a great day!
```
